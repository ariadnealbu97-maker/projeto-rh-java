# 💻 Sistema de Gestão e Reajuste de Recursos Humanos (RH)

Este é um sistema desenvolvido em Java focado na automação de processos do departamento de Recursos Humanos. O software simula o gerenciamento de colaboradores e possui um módulo prático para aplicação de reajustes salariais gerais de forma automatizada.

---

## 🚀 Funcionalidades Principais

* **Visualização de Colaboradores:** Exibição detalhada dos dados cadastrados (Nome, CPF, Endereço, Telefone e Setor).
* **Cálculo de Reajuste Salarial Geral:** O sistema solicita uma porcentagem de aumento e atualiza instantaneamente o pagamento de todos os funcionários.
* **Organização por Setores:** Divisão e controle de profissionais em setores como Administrativo (Adm), Recursos Humanos (RH) e Logística.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **IDE:** NetBeans
* **Paradigma:** Programação Orientada a Objetos (POO)
